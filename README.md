# Learning C++ Projects

This repository is for the coding projects I do while learning C++.

The first project (`Numword`) converts integer numbers to their English word representations. It was my final project for a [LinkedIn Learning course](https://www.linkedin.com/learning/c-plus-plus-development-advanced-concepts-lambda-expressions-and-best-practices/). My goal is also to revisit it and add further functionality in the future. 

The second project (`Level Up Challenges`) contains a number of small programming challenges meant to improve my C++ proficiency. The exercises were taken from a [LinkedIn Learning course](https://www.linkedin.com/learning/level-up-c-plus-plus), but all the solutions are my own. 

I hope to add more projects here as I continue learning.

Note on AI use: As this is a repository meant for me to improve my C++ skills, I try to employ minimal use of AI. I do however ask for guidance, grading and sources of potential improvements primarily from Opencode Free Tier models while completing these projects. I also do occasionally employ OpenCode's agent AI to write additional test cases for my functions after I have established the first few but no core function logic is written by AI. AI is only ever used towards the end of a project, and never in the initial stages.
